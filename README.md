# Calculadora em Python

Calculadora com interface gráfica desenvolvida em **Python** utilizando a biblioteca **Tkinter**.

O programa permite realizar operações matemáticas básicas por meio de uma interface simples e interativa.

## Funcionalidades

* Adição
* Subtração
* Multiplicação
* Divisão
* Porcentagem
* Uso de parênteses
* Números decimais
* Limpeza da expressão
* Tratamento básico de erros

## Tecnologias utilizadas

* Python
* Tkinter

## Como executar

Clone o repositório ou baixe o arquivo e execute:

```bash
python calc.py
```

## Estrutura

```text
calculadora/
└── calc.py
```

O projeto utiliza a classe `Calculator` para organizar a interface e as operações da calculadora.
